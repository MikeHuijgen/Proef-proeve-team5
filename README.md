# Proef-proeve-team5
## General
This is our practice exam for software developer and game artist. We make a mobile game that is inspired by [stumble guys](https://www.stumbleguys.com/nl). Our game is about an astronaut that needs to parkour from planet to planet. The player has to dodge obstacals, jump from platform to platform and dodge the aliens that habit the planet.

We document everything we do for this project inside the Github [Wiki](https://github.com/MikeHuijgen/Proef-proeve-team5/wiki).
